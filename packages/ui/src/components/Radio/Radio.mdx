# Radio

`Radio` est un bouton radio natif. Utilisez-le dans un `RadioGroup` pour un choix exclusif.

Les exemples suivent la **langue** de la barre d’outils Storybook (**Français** par défaut).

<Canvas of={RadioStories.Default} />

## États particuliers

Deux états particuliers : `disabled` et `invalid`.

### Désactivé

Utilisez `disabled` sur le groupe lorsque la valeur ne peut pas être modifiée.

<Canvas of={RadioStories.Disabled} />

### Invalide

Utilisez `invalid` (et `error` pour le message) pour indiquer qu’aucune option n’est considérée comme correcte. Le groupe pose `aria-invalid` sur le `fieldset`.

<Canvas of={RadioStories.Invalid} />

## Options

### Requis

Utilisez `required` sur le groupe pour exiger une sélection avant l’envoi du formulaire. Un astérisque est affiché à côté de la légende.

<Canvas of={RadioStories.Required} />

### Aide

Utilisez `helper` pour donner une indication.

<Canvas of={RadioStories.Helper} />

### Tailles

`sm` lorsque l’espace est contraint, `md` par défaut, `lg` pour les formulaires aérés.

<Canvas of={RadioStories.Sizes} />

## Groupe

`RadioGroup` enveloppe les options dans un `fieldset` nommé par `label` (`<legend>`). Toutes les radios partagent le même `name`. La valeur est une chaîne.

<Canvas of={RadioStories.Default} />

### Disposition

`orientation="horizontal"` aligne les options sur une ligne.

<Canvas of={RadioStories.Horizontal} />

## Accessibilité

`Radio` rend un `<input type="radio">` natif. Le groupe utilise `fieldset` + `legend`. Les flèches déplacent la sélection dans le groupe.

Associez toujours un label visible par option. La légende du groupe nomme l’ensemble, pas chaque radio.

### À faire

- `RadioGroup` + `Radio` avec `value` distinctes
- Un `name` **par groupe** sur la page (ou omettre `name` : un identifiant est généré)
- `invalid` **et** un message `error` (ne pas se fier à la couleur seule)

### À éviter

- Des radios sans groupe nommé
- Segmented control (hors périmètre)
- Simuler un choix exclusif avec des cases à cocher

Thème sombre : barre d’outils **Thème**. Langue des exemples : barre d’outils **Langue**.

## Propriétés

Les attributs natifs `<input>` (`name`, `className`, …) sont transmis au contrôle. `value` est obligatoire.
