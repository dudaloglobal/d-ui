# Typographie

`Text`, `Heading`, `Link` et `Divider` sont les primitives sur lesquelles reposent tous
les autres composants. Un écran qui écrit `text-[17px]` ou `#475569` en dur ne passe pas
la revue : ces quatre composants existent pour rendre ça inutile.

## Échelle

L'échelle est celle de Tailwind, exposée sous des rôles sémantiques. Voir
[ADR 0001](https://github.com/dudaloglobal/d-ui/blob/main/docs/adr/0001-fondations-tokens.md).

| Rôle       | Composant          | Classe      |
| ---------- | ------------------ | ----------- |
| `display`  | `Heading`          | `text-4xl`  |
| `title`    | `Heading`          | `text-2xl`  |
| `subtitle` | `Heading`          | `text-xl`   |
| `body`     | `Text` / `Heading` | `text-base` |
| `body-sm`  | `Text`             | `text-sm`   |
| `caption`  | `Text`             | `text-xs`   |

## Usage

```tsx
import { Divider, Heading, Link, Text } from 'd-ui';
import 'd-ui/styles.css';

<article>
  <Heading level={1}>Parcours d’apprentissage</Heading>
  <Text tone="muted" size="body-sm">
    Mis à jour il y a deux jours
  </Text>
  <Divider />
  <Text>
    Consultez le <Link href="/catalogue">catalogue</Link> pour choisir un module.
  </Text>
</article>;
```

Les tableaux de props de chaque composant sont générés automatiquement dans
`Components / Text`, `Heading`, `Link` et `Divider`.

## Accessibilité

- **Le niveau de titre porte la structure, pas l'apparence.** `Heading` sépare `level` de
  `size` précisément pour qu'on n'ait jamais à sauter un niveau pour obtenir la bonne
  taille — ce qui casserait la navigation par titres (WCAG 1.3.1).
- **Les liens sont soulignés en permanence.** La couleur seule ne suffit pas à identifier
  un lien dans un paragraphe (WCAG 1.4.1).
- **Un lien externe s'annonce.** `external` ajoute `rel="noopener noreferrer"` et un texte
  masqué « (ouvre dans un nouvel onglet) ».
- **`Divider` est décoratif par défaut**, donc masqué aux lecteurs d'écran. Le `label`
  n'est justifié que si la séparation porte réellement du sens.
- **`tone="muted"` reste au-dessus de 4.5:1** dans les deux thèmes. C'est une nuance de
  hiérarchie, pas une autorisation de baisser le contraste — le test
  `tokens.contrast.test.ts` le vérifie à chaque CI.

## À faire / à éviter

| ✅ À faire                                        | ❌ À éviter                                          |
| ------------------------------------------------- | ---------------------------------------------------- |
| `<Heading level={2} size="display">`              | `<Heading level={1}>` deux fois sur une page         |
| `<Text tone="muted">` pour une métadonnée         | `<Text className="text-slate-400">`                  |
| `<Link external>` pour une cible hors application | `target="_blank"` posé à la main sans `rel`          |
| `<Divider />` entre deux blocs visuels            | `<Divider label="…" />` sur chaque ligne d'une liste |
