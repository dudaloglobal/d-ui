# Switch

`Switch` est un interrupteur pour un réglage immédiat (on / off). Pour un accord ou un choix de formulaire, préférez `Checkbox`.

Les exemples suivent la **langue** de la barre d’outils Storybook (**Français** par défaut).

<Canvas of={SwitchStories.Default} />

## États particuliers

Trois états particuliers : activé, `disabled` et `invalid`.

### Activé

Passez `checked` (contrôlé) ou `defaultChecked` (non contrôlé).

<Canvas of={SwitchStories.On} />

### Désactivé

Utilisez `disabled` lorsque la valeur ne peut pas être modifiée.

<Canvas of={SwitchStories.Disabled} />

### Invalide

Utilisez `invalid` (et `error` pour le message) pour indiquer que la valeur est considérée comme incorrecte. `invalid` pose `aria-invalid`.

<Canvas of={SwitchStories.Invalid} />

## Options

### Requis

Utilisez `required` pour indiquer que l’interrupteur doit être activé avant l’envoi du formulaire. Un astérisque est affiché à côté du libellé.

<Canvas of={SwitchStories.Required} />

### Aide

Utilisez `helper` pour donner une indication.

<Canvas of={SwitchStories.Helper} />

### Tailles

`sm` lorsque l’espace est contraint, `md` par défaut, `lg` pour les formulaires aérés.

<Canvas of={SwitchStories.Sizes} />

## Accessibilité

`Switch` rend un `<input type="checkbox" role="switch">`. L’état est exposé par `aria-checked` (`true` / `false`). Associez toujours un nom accessible : prop `label`, `aria-label`, ou `aria-labelledby`.

Espace et clic basculent l’état. Le focus visible utilise l’anneau `ring-focus`.

### À faire

- `<Switch label="Mode compact" />`
- `aria-label` si le libellé n’est pas visible
- `invalid` **et** un message `error` (ne pas se fier à la couleur seule)

### À éviter

- Un interrupteur sans nom accessible
- Remplacer un groupe radio par une rangée d’interrupteurs
- Segmented control (hors périmètre)

Thème sombre : barre d’outils **Thème**. Langue des exemples : barre d’outils **Langue**.
