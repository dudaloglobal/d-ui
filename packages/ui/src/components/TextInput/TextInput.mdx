# TextInput

`TextInput` est le champ de saisie d’une ligne, en pleine largeur. Pour plusieurs lignes, utilisez `Textarea`.

Les exemples suivent la **langue** de la barre d’outils Storybook (**Français** par défaut).

`label` est une prop du composant : le libellé s’affiche au-dessus du cadre. Vous pouvez aussi attacher un `<label htmlFor>` externe ou `aria-labelledby` (par exemple via `Field`, DS-022).

## États particuliers

Trois états particuliers : `disabled`, `valid` et `invalid`.

### Désactivé

Utilisez `disabled` lorsque la valeur ne peut pas être modifiée.

<Canvas of={TextInputStories.Disabled} />

### Valide

Utilisez `valid` pour indiquer que la valeur saisie est considérée comme correcte.

<Canvas of={TextInputStories.Valid} />

### Invalide

Utilisez `invalid` (et `error` pour le message) pour indiquer que la valeur saisie est considérée comme incorrecte. `invalid` pose `aria-invalid`.

<Canvas of={TextInputStories.Invalid} />

## Options

Options : `required`, `helper`, `placeholder`, `icon`, `clearable`, `maxLength`. Les chips sont hors périmètre.

### Requis

Utilisez `required` pour indiquer que le champ doit être renseigné avant l’envoi du formulaire. Un astérisque est affiché à côté du libellé.

<Canvas of={TextInputStories.Required} />

### Aide

Utilisez `helper` pour donner une indication.

<Canvas of={TextInputStories.Helper} />

### Texte de substitution

Utilisez `placeholder` pour donner un exemple de valeur attendue ou inviter à remplir le champ.

<Canvas of={TextInputStories.Placeholder} />

### Icône

Utilisez `icon` pour illustrer le champ. `icon` complète `label` mais ne le remplace pas.

<Canvas of={TextInputStories.Icon} />

### Effaçable

`clearable` affiche un bouton d’effacement dès que la valeur n’est pas vide. Passez `clearLabel` (nom accessible) et `onClear` si la valeur est contrôlée.

<Canvas of={TextInputStories.Clearable} />

### Longueur maximale

Utilisez `maxLength` lorsque la longueur de saisie est limitée. Le compteur (caractères restants) s’affiche à droite du libellé. Localisez le texte avec `countMessage`.

<Canvas of={TextInputStories.MaxLength} />

### Préfixe et suffixe

Les slots `prefix` et `suffix` illustrent le champ (unité, schéma d’URL). Ils ne remplacent pas le label.

<Canvas of={TextInputStories.PrefixSuffix} />

### Tailles

`sm` lorsque l’espace est contraint, `md` par défaut, `lg` pour les formulaires aérés.

<Canvas of={TextInputStories.Sizes} />

## Nombre

Utilisez `type="number"` lorsque la valeur attendue est numérique. `inputMode="numeric"` aide le clavier logiciel.

<Canvas of={TextInputStories.Number} />

## Mot de passe

`type="password"` masque la saisie et propose un basculeur de visibilité nommé (pas seulement une icône).

## Accessibilité

`TextInput` rend un `<input>` natif. Pour plusieurs lignes, utilisez `Textarea`.

Associez toujours un label visible : prop `label`, `aria-labelledby`, ou un `<label htmlFor>` externe. Un placeholder ne suffit pas.

Lorsque `maxLength` est posé, fournissez `countMessage` localisé (par exemple « n caractères restants »). Le compteur est lié par `aria-describedby` : il n’y a pas d’`aria-live` à chaque frappe.

Le champ peut être désactivé de deux façons :

- `disabled` désactive complètement le champ : il n’est plus focusable et les événements pointeur sont ignorés. Indiquez autrement pourquoi le champ est là et pourquoi il est désactivé.
- `readOnly` / `aria-disabled` empêche l’édition tout en laissant le focus. Expliquez la raison via `helper`, un tooltip ou une description ARIA.

### À faire

- `<TextInput label="Email" type="email" autoComplete="email" />`
- `clearLabel` / `revealPasswordLabel` dans la langue de l’app
- `countMessage` localisé lorsque `maxLength` est posé
- `invalid` **et** un message `error` (ne pas se fier à la couleur seule)

### À éviter

- Un champ identifié seulement par le placeholder
- Remplacer le label par `icon`
- Masquer le mot de passe derrière une icône sans nom accessible
- Saisie masquée (carte), texte riche, OTP, chips — hors périmètre
