# Button

Les boutons déclenchent une action en un clic.

Les exemples suivent la **langue** de la barre d’outils Storybook (**Français** par défaut).

## Forte emphase

Utilisez le fort emphasis (`variant="primary"`) pour aider à identifier l’action principale. Il ne doit pas y avoir plus d’un bouton high emphasis dans une vue.

Cas d’usage : Par défaut, Désactivé, Chargement, Avec icône, Menu, Fractionné.

<Canvas of={ButtonStories.HighEmphasis} />

## Emphase moyenne

Utilisez le medium emphasis (`variant="secondary"`) pour les actions secondaires.

<Canvas of={ButtonStories.MediumEmphasis} />

### Bouton bascule

Les boutons medium ont une option supplémentaire : `isSelected`. Utilisez `isSelected` pour des actions à bascule (activation de notifications, abonnement à un flux). Décrivez l’action le plus clairement possible dans le libellé.

<Canvas of={ButtonStories.Toggled} />

## Faible emphase

Quand la vue contient déjà un bouton primary et un medium, utilisez le low emphasis (`variant="ghost"`) pour les actions de moindre priorité. Autrement, utilisez-le lorsqu’il n’y a qu’un seul niveau de priorité.

Cas d’usage : Par défaut, Désactivé, Chargement, Avec icône, Menu (pas de fractionné).

<Canvas of={ButtonStories.LowEmphasis} />

## Chargement

`loading` affiche un indicateur, conserve le libellé, pose `aria-busy` et désactive le contrôle. L’icône est remplacée par l’indicateur. `loadingIndicator="spinner"` (défaut) ou `"bounce"`.

<Canvas of={ButtonStories.Loading} />

## Petite taille

Utilisez la petite taille (`size="sm"`) lorsque l’espace est contraint.

<Canvas of={ButtonStories.SmallSize} />

## Pleine largeur

Utilisez `fullWidth` lorsque le bouton doit occuper toute la largeur du conteneur.

<Canvas of={ButtonStories.FullWidth} />

Menu et fractionné sont des **compositions** de `Button` / `IconButton` (chevron, `aria-haspopup`). Le menu déroulant complet arrive avec Menu (DS-030).

### Accessibilité

#### Button

Le bouton utilise le texte visible comme nom accessible. S’il n’y a pas de texte (icône seule, image, …), passez un `aria-label` qui décrit l’action.

Cas d’usage accessibilité :

- **Bouton natif** — `Button` rend un `<button type="button">`. Pour la navigation, utilisez un lien (`Link`, DS-019).
- **Toggle** — état actif/inactif via `isSelected`. Si le libellé change selon l’état (`S'abonner` / `Abonné`), ce nom suffit. Si le libellé ne change pas, `aria-pressed` est posé depuis `isSelected`.
- **Menu** — si le bouton ouvre une liste : `aria-haspopup="true"`, `aria-expanded` selon l’ouverture, et `aria-controls` vers l’id du menu uniquement si le menu est dans le DOM.
- **Chargement** — `loading` conserve le libellé, pose `aria-busy` et désactive le contrôle. `loadingIndicator` choisit spinner ou bounce.

#### IconButton

Toutes les règles de `Button` s’appliquent. Comme il n’y a pas de texte, `aria-label` est obligatoire.

## Propriétés

### Button

Les attributs natifs `<button>` (`disabled`, `type`, `className`, `aria-haspopup`, …) sont transmis.

### IconButton

`IconButton` exige `aria-label`. `icon`, `variant`, `size`, `loading`, `loadingIndicator`, `fullWidth` et `isSelected` sont les mêmes que `Button`.
