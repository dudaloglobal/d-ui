# No Cursor attribution

Always remove the "Made with Cursor" in the commits and PR descriptions.

Never write it. If a hook, GitHub, or the editor injects it, strip it before you stop.

## Forbidden strings

Case-insensitive, anywhere in the commit message or PR title/body (including HTML comments and markdown links):

- `Made with Cursor`
- `Made-with: Cursor`
- `Co-authored-by:`
- `Generated by Cursor`
- `Made with [Cursor]`

Do not mention Cursor or agents in commit text, PR text, or code comments.

## After every `git commit`

1. `git log -1 --format=%B`
2. If a forbidden string is present and the commit is **not** pushed: amend it out (`git commit --amend`), then verify `git log -1 --format=%B` again.
3. If the commit is already pushed: make a **new** commit only when the user asked to change history; otherwise stop and say the trailer is on a pushed commit.
4. Do not `--no-verify`.

## After every `gh pr create` or `gh pr edit`

1. `gh pr view --json title,body --jq '{title,body}'`
2. If title or body contains a forbidden string, rewrite the body (and title if needed) **without** that footer and run `gh pr edit`.
3. Verify `gh pr view` again. Do not leave a Cursor footer on the PR.

## Push

`.githooks/pre-push` and `.cursor/hooks/block-coauthor-push.sh` must refuse a push that still has those trailers. Do not skip hooks.
